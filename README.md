## The outcome

Build a permission-aware outreach pipeline with human approval before every send. This skill covers lead tracking, qualification, scoring, email sequences, rate limits, and morning briefings.

## What you get

A structured lead workflow that scores opportunities, drafts relevant outreach, respects rate limits, and keeps sending under human control.

## Quick start

1. Install the ClawHub skill: `openclaw-email-lead-generation`
2. Run `/email-lead-gen`
3. Define the audience, qualification rules, evidence sources, sending account, and approval boundary. Keep human review before every send.
4. Review the output before publishing, sending, or changing live systems.

## A useful first prompt

```text
Use /email-lead-gen with me. First ask only for the information you need to produce a reliable result. Do not invent missing facts, claims, prices, owners, or deadlines. Show me the draft before anything is published or sent.
```
